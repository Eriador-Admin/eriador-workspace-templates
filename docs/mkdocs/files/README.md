# {{PROJECT_NAME}}

A documentation site built with [MkDocs](https://www.mkdocs.org/) and the [Material](https://squidfunk.github.io/mkdocs-material/) theme.

## Getting Started

```bash
bash init.sh    # create venv & install deps
bash run.sh     # start dev server
bash stop.sh    # stop dev server
```

## Project Structure

```
docs/           # Markdown documentation pages
mkdocs.yml      # Site configuration
```

## Writing Docs

Add `.md` files to the `docs/` directory. Update `mkdocs.yml` nav section to control the sidebar.

## Requirements

- Python 3.11+
