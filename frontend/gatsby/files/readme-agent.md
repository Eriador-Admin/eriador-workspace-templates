# Agent Instructions — {{PROJECT_NAME}}

This is a Gatsby static site project.

## Tech Stack
- **Framework**: Gatsby 5
- **Language**: TypeScript
- **UI**: React
- **Data**: GraphQL (Gatsby's data layer)
- **Content**: MDX

## Key Conventions
- Pages in `src/pages/` (file-system routing)
- Blog posts in `content/blog/` as `.mdx` files
- Templates in `src/templates/` (programmatic pages)
- Use `useStaticQuery` and page queries for data
- Gatsby Node APIs in `gatsby-node.ts`
- Config in `gatsby-config.ts`
