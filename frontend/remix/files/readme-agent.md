# Agent Instructions — {{PROJECT_NAME}}

This is a React Router (formerly Remix) full-stack application in framework mode.

## Tech Stack
- **Framework**: React Router 8 framework mode (the Remix v2 successor)
- **UI**: React 19
- **Bundler**: Vite 8
- **Language**: TypeScript
- **Runtime**: Node.js (`@react-router/node`, served by `@react-router/serve`)

## Key Conventions
- Root layout: `app/root.tsx`
- Routes are declared in `app/routes.ts` (`index(...)`, `route(path, file)`); each points at a route module in `app/routes/`
- Use `loader` for server-side data fetching, `action` for form mutations
- Import runtime APIs (`Link`, `Outlet`, `Meta`, ...) from `react-router`
- Route types come from `./+types/<route>` (generated by `react-router typegen`, run by `npm run typecheck`)
- Framework options (SSR, prerender) live in `react-router.config.ts`

## Adding a page
1. Create `app/routes/<name>.tsx` exporting a default component (and optional `meta` / `loader` / `action`)
2. Add `route("<path>", "routes/<name>.tsx")` to `app/routes.ts`
