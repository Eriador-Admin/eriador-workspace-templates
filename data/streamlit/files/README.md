# {{PROJECT_NAME}}

An interactive data dashboard built with [Streamlit](https://streamlit.io/).

## Getting Started

```bash
bash init.sh    # create venv and install dependencies
bash run.sh     # start the Streamlit app
bash stop.sh    # stop the app
```

## Project Structure

```
app.py              # Main Streamlit application
pages/
  01_charts.py      # Chart visualizations page
  02_data.py        # Raw data explorer page
data/
  sample.csv        # Sample dataset
requirements.txt    # Python dependencies
```

## Requirements

- Python 3.9+
