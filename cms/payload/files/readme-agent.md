# Agent Instructions — {{PROJECT_NAME}}

This is a Payload CMS project.

## Tech Stack
- **CMS**: Payload CMS 3.x
- **Database**: MongoDB (Docker) via `@payloadcms/db-mongodb`
- **App Server**: Next.js 16 (Payload 3 runs inside the Next.js app)
- **Rich text**: Lexical (`@payloadcms/richtext-lexical`)

## Key Conventions
- Config: `src/payload.config.ts` (imports from `payload`, not `payload/config`)
- Routes: `src/app/(payload)/` — generated by Payload; do not hand-edit
- After adding custom/admin components or rich-text features run `npm run generate:importmap`
- `npm run generate:types` writes `src/payload-types.ts`
- Collections in `src/collections/`
- Admin panel at /admin, REST API at /api
- Media uploads stored locally in project root
- Users collection has auth enabled
