# Agent Instructions — {{PROJECT_NAME}}

This is a Jupyter notebook data science project.

## Tech Stack
- **Environment**: Jupyter Lab / Notebook
- **Libraries**: pandas, numpy, matplotlib, seaborn, scikit-learn
- **Language**: Python 3.11+

## Key Conventions
- Notebooks in `notebooks/` — numbered for order
- Raw data in `data/raw/`, processed data in `data/processed/`
- Shared utilities in `src/utils.py`
- Keep notebooks focused on one task each

## File Patterns
- `notebooks/*.ipynb` → Jupyter notebooks
- `data/raw/*` → Source data (CSV, JSON, etc.)
- `data/processed/*` → Cleaned output data
- `src/*.py` → Reusable Python modules
