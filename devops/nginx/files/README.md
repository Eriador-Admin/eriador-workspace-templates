# {{PROJECT_NAME}}

[Nginx](https://nginx.org/) reverse proxy and load balancer with Docker-based sample backends.

## Getting Started

```bash
bash init.sh    # build and start everything
bash run.sh     # follow logs
bash stop.sh    # stop all services
```

## Services

| Service | URL | Description |
|---------|-----|-------------|
| Nginx | `http://localhost` | Main entry point |
| API (upstream) | proxied via `/api/` | Round-robin load balanced (2 replicas) |
| Static files | `http://localhost/` | Served directly by Nginx |
| Health check | `http://localhost/health` | Nginx stub status |

## Architecture

```
                     ┌─────────┐
  Client ──────────► │  Nginx  │
                     │ :80/:443│
                     └────┬────┘
                          │
              ┌───────────┼───────────┐
              ▼           ▼           ▼
         ┌────────┐ ┌────────┐ ┌──────────┐
         │ API #1 │ │ API #2 │ │  Static  │
         │ :3000  │ │ :3000  │ │  Files   │
         └────────┘ └────────┘ └──────────┘
```

## Project Structure

```
nginx/
  nginx.conf            # Main Nginx config
  conf.d/
    default.conf        # Server block with upstream, locations
    security.conf       # Security headers
    gzip.conf           # Gzip compression settings
  ssl/                  # Self-signed certs (generated by init.sh)
services/
  api/Dockerfile        # Sample Node.js API backend
static/
  index.html            # Sample static page
docker-compose.yml
```

## Configuration Highlights

- **Load balancing**: Round-robin across API replicas
- **Gzip**: Enabled for text, JSON, CSS, JS, SVG
- **Security headers**: X-Frame-Options, CSP, XSS protection
- **Rate limiting**: 10 req/s per IP on API routes
- **Static caching**: 30-day cache for assets
- **Health endpoint**: Nginx stub_status module

## Self-Signed SSL (Dev)

`init.sh` generates a self-signed certificate in `nginx/ssl/`. For production, replace with real certs or use Certbot.

```bash
# Access via HTTPS (self-signed, browser will warn)
https://localhost
```
