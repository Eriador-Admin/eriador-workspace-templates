# Agent Instructions — {{PROJECT_NAME}}

This is a Nuxt 4 full-stack application.

## Tech Stack
- **Framework**: Nuxt 4
- **Language**: TypeScript / Vue 3
- **Server Engine**: Nitro

## Key Conventions
- App source lives in `app/` (Nuxt 4 layout); `server/` stays at the project root
- File-based routing in `app/pages/`
- Server API routes in `server/api/`
- Layouts in `app/layouts/`
- Composables in `app/composables/`
- Use `useFetch` / `useAsyncData` for data fetching
- Auto-imports for Vue/Nuxt APIs
