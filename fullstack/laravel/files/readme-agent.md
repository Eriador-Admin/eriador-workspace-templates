# Agent Instructions — {{PROJECT_NAME}}

This is a Laravel PHP full-stack application.

## Tech Stack
- **Framework**: Laravel 11
- **Language**: PHP 8.2+
- **Template Engine**: Blade
- **ORM**: Eloquent
- **Database**: MySQL (via Docker)

## Key Conventions
- Routes: `routes/web.php` (web), `routes/api.php` (API)
- Controllers: `app/Http/Controllers/`
- Models: `app/Models/`
- Views: `resources/views/` with `.blade.php` extension
- Migrations: `database/migrations/`
- Config: `.env` file (copy from `.env.example`)
- Use `php artisan` for CLI commands
