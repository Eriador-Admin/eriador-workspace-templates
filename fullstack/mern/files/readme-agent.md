# Agent Instructions — {{PROJECT_NAME}}

This is a MERN stack (MongoDB, Express, React, Node.js) project.

## Tech Stack
- **Backend**: Express + Mongoose + TypeScript
- **Frontend**: React + Vite + TypeScript
- **Database**: MongoDB

## Key Conventions
- Backend in `backend/`, frontend in `frontend/`
- Mongoose models in `backend/src/models/`
- API routes in `backend/src/routes/`
- Frontend proxies `/api` to backend via Vite config
- MongoDB runs in Docker on port 27017
