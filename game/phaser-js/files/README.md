# {{PROJECT_NAME}}

An HTML5 game built with [Phaser 3](https://phaser.io/) and [Vite](https://vitejs.dev/).

## Getting Started

```bash
bash init.sh    # install dependencies
bash run.sh     # start dev server
bash stop.sh    # stop dev server
```

## Project Structure

```
src/
  main.js         # Game configuration and entry point
  scenes/
    Boot.js       # Asset loading scene
    Game.js       # Main game scene
public/
  assets/         # Game assets (images, audio, etc.)
index.html        # HTML entry point
```

## Requirements

- Node.js 18+
