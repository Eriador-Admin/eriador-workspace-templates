# {{PROJECT_NAME}}

A 2D game built with [Godot Engine](https://godotengine.org/).

## Getting Started

```bash
bash init.sh    # verify Godot installation
bash run.sh     # open project in Godot editor
bash stop.sh    # (no-op)
```

## Project Structure

```
scenes/
  Main.tscn       # Main scene
  Player.tscn     # Player scene
scripts/
  Player.gd       # Player movement script
project.godot     # Godot project file
```

## Requirements

- Godot Engine 4.2+ (install from https://godotengine.org/download)
- Add `godot` to your PATH, or open the project file directly from the Godot editor
